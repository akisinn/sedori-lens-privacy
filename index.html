プライバシーポリシー

本ポリシーは、せどりレンズ（以下「本アプリ」）における個人情報の取り扱いについて定めるものです。

1. 収集する情報

本アプリは、ユーザーを識別する個人情報を収集しません。アカウント登録・ログイン機能はありません。

2. カメラの使用

本アプリは商品の識別を目的としてカメラを使用します。撮影された画像はAI解析のため、当社サーバーおよびAnthropic, Inc. が提供するClaude API に送信されます。画像はAnthropicを含むいかなる場所においても解析後に保持・保存されることはありません。

3. 通信について

画像の解析処理はHTTPS暗号化通信によって行われます。ユーザーを特定できる情報は含まれません。

4. 利用する第三者サービス

本アプリは以下の第三者サービスを利用しています。各サービスのプライバシーポリシーも併せてご確認ください。

  • Anthropic Claude API（画像解析）:
    https://www.anthropic.com/privacy
  • Apple In-App Purchase（サブスクリプション決済）:
    https://www.apple.com/legal/privacy/jp/
  • RevenueCat（購入・サブスク状態の管理）:
    https://www.revenuecat.com/privacy

Apple In-App Purchaseによる決済情報はAppleが管理し、当社は参照できません。RevenueCatは購入復元のためにアプリ固有の匿名識別子を使用します。いずれのサービスにおいても個人を特定する情報は取り扱いません。

5. 個人情報の第三者提供

ユーザーの個人情報を第三者に販売・提供することは一切行いません。
